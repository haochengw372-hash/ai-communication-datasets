# Reference materials

`methods.json` is the frozen initial protocol and source-method extraction. Its
`protocol_not_executed` status describes that planning artifact; it does not claim
that every proposed step was run. `../replications/deviation_matrix.csv` and the
two executed manifests specify what was actually implemented on the new sample.
In particular the Hara example uses organizations, without expert screening,
human role labels, BTM or role regressions. No article PDF is redistributed.
